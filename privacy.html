Privacy policy

This policy covers the Google OAuth application named rclone, configured and operated by Bob Yang for personal Google Drive file operations, and this informational website.

Data accessed and purpose

After the operator authorizes access through Google, rclone may access Google Drive file contents and metadata, such as names, folder paths, identifiers, sizes, and modification times. The exact access depends on the OAuth permissions granted. Full Drive access can allow reading, creating, changing, and deleting files.

This access is used for operator-directed listing, copying, backup, synchronization, and other file-management commands. This client is intended for the operator's own account, not public account registration.

Storage and security

rclone runs on devices or systems controlled by the operator. OAuth tokens and configuration are stored by rclone on those systems; they are not sent to or stored by this informational website. Copied files are stored on the devices or destinations selected by the operator. rclone configuration, logs, caches, and backups may retain credentials, file metadata, or copies until the operator removes them.

The operator is responsible for restricting access to devices, protecting credentials and backups, and selecting appropriate storage permissions. Transfers to Google Drive use Google's HTTPS API.

Sharing and limited use

Google user data is used only to provide the file operations requested by the operator. Files and associated metadata may be transferred to storage providers or recipients explicitly selected by the operator. This setup does not sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models.

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion, and revoking access

The operator controls retention of copied files, configuration, caches, logs, and backups, subject to the retention features of any selected storage provider. Copies remain until deleted from those locations; disconnecting Google access does not automatically delete existing copies.

Access can be revoked in Google Account third-party connections by selecting this application and removing its access. To remove local authorization, the operator can disconnect or delete the corresponding rclone remote and remove any retained credentials or backups. Files and logs can be deleted separately from their storage locations.

This website

This is a static informational website hosted by GitHub Pages. It has no sign-in form, advertising, embedded trackers, or analytics added by the operator. It does not collect Drive files or OAuth credentials. GitHub may process visitor connection information, including IP addresses, under the GitHub General Privacy Statement. Google and any storage providers separately process data under their own policies.
